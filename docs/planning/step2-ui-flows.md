## UI-BASE 共用框架

```text
┌ Work Station                  搜索 Ctrl+K      保存状态 ┐
│ 今日首页     │ 页面标题                         帮助    │
│ LaTeX 笔记   │ 页面工具栏                               │
│ DDL 提醒     │ 筛选/列表             选中项详情          │
│ 随手记       │                                         │
│ 密码簿       │ 当前操作反馈（文字＋图标）                │
│ 课表         │                                         │
│ 外观设置     │                                         │
│ 数据管理     │                                         │
│ 设置         │                                         │
└──────────────┴─────────────────────────────────────────┘
```

最小主窗口960×640逻辑像素；字体100%—150%（默认100%），Windows显示缩放100/125/150/200%分别测试。窄窗列表与详情切换为单栏，笔记编辑/预览改页签，课表允许横向滚动且固定时间列，避免缩小到不可读。快捷窗口最小420×300。尺寸为待V-UI验证的工程初值；工作区小于最小尺寸时自适应至可用区并保留滚动访问全部控件。

Tab/Shift+Tab遍历，Enter激活按钮，Space切复选框，Esc关闭可取消弹层，弹层有焦点约束与明确退出，关闭返回触发点。Ctrl+K搜索、Ctrl+N当前页新建、Ctrl+S立即保存普通编辑/提交密码簿编辑、Ctrl+Enter提交快捷记录；不覆盖文本框原有编辑键。删除用带名称和范围的确认，不绑定单独Delete误触。首次引导说明本地未加密普通数据、独立密码簿、密码不可找回、托盘与彻底退出、三种备份和清除。

减少动态效果默认跟随系统，可选始终减少；焦点轮廓、文字状态不依赖颜色。正文/背景对比目标4.5:1，大字与控件目标3:1；图片背景加稳定面板遮罩，低对比时给警告与恢复默认入口。缩放测试含长中文标签、错误提示、密码掩码、课表多重冲突；不能仅看静态图认定可用。

```text
[最近笔记]                         [最近随手记]
[重启期间到期任务，查看]            [提醒记录]
```

空状态分别为“今天没有课程”“暂无待办”“新建第一篇笔记”；学期外显示“未开学/学期已结束”及手动查看周次入口，不自动列课。加载时骨架＋“正在读取本地数据”；失败显示重试/数据管理恢复，不假装空列表。

## UI-02 LaTeX笔记

```text
[新建] [标题/标签筛选]    标题：[虚构：微积分复习] 标签：[数学]
笔记列表                 [上下标 分式 根号 求和 积分 希腊字母 运算符 矩阵 分段 环境]
最近更新                 [Markdown编辑区] | [公式与正文预览]
选中项                   [保存中… / 已保存 10:01 / 保存失败，重试]
                         [删除笔记]
```

F-01：新建→输入标题正文→在光标点插公式（有选区则包裹）→预览→自动保存→重启恢复。工具栏例：x^{…}、x_{…}、\frac{…}{…}、\sqrt{…}、\sum、\int、\alpha、\le、pmatrix、cases、aligned；代码区不会被公式解析。无效公式：“此处公式暂时无法显示，请检查括号或命令”，保留可编辑源文；预览超时：“内容较复杂，已暂停预览，正文仍可保存”。删除确认只针对该笔记，不删共享标签。

## UI-03 DDL提醒

```text
[新建任务] [分类管理] [标签] [提醒记录] [未完成｜已完成｜周期]
逾期 / 今日 / 未来7天 / 更晚        任务详情：截止、备注、分类、标签
各组列表                           [完成/恢复未完成] [删除本期]
周期列表 → 某周期                   规则说明 [修改后续] [停止周期]
                                   各期历史：日期｜状态｜查看
```

F-03：新建→单次/周期→选择起始日、时间、间隔、星期或月日、提前提醒→只读“下一计划时间”→保存规则。计划预览不当作已生成任务。修改显示“已有各期保持原计划；新规则从保存后生效”。停止周期说明保留历史；“删除周期及全部历史”另有二次确认。恢复旧期提示“已恢复为未完成，不会再次通知”，逾期列表出现该期而其他期不变。

停止后的周期有“重新开启”，先预览下一计划时间并说明“停用期间的期次不会补建”；开启不改变旧历史。只调整提前量时提示“已提醒的这期不会再次通知”。

F-04：08:50点击09:00期的通知→显示“计划于09:00到期，届时生成记录”及规则入口；09:00刷新为正式期详情。旧计划失效时显示“计划已变更”，已跳过时显示“本期未建立任务记录”。提醒记录为DDL页内面板而非第十一级页面：按汇总时间分组、每条可定位、标明已发送/仅应用内/未送达；休眠后“有3条待查看提醒”一条通知展开全部事件，不冒充生成3期。

## UI-04 随手记

```text
[新建] [标签筛选] [搜索]      标题 [可空，显示未命名]
按更新时间降序列表           正文输入 / 预览
                             标签；创建/更新时间；保存状态；删除
```

F-02：全局快捷键→小窗口（正文自动聚焦）→输入虚构内容→Ctrl+Enter→等待已保存再关闭→主窗口列表即时刷新。Esc有未保存内容时提供继续编辑/保存后关闭/放弃；失败窗口保持可重试，不消失。快捷键冲突：“这个组合键已被占用，请换一个”；退出后不响应，设置页明确说明。

## UI-05 密码簿

```text
未设置：[创建主密码] [再次输入] [主密码无法找回的说明]
已锁定：[输入主密码] [解锁] [从加密备份恢复]
已解锁：[簿内搜索] [新增] [立即锁定] [修改主密码] [独立备份/恢复]
条目列表 | 平台 用户名 密码•••• [显示15秒] [复制] 网址 备注
         | [编辑] [保存] [取消] [删除]
         | 锁定时未保存的修改会丢失
```

F-06a：首次设置两次密码→无法找回说明→解锁列表；错误密码统一“密码不正确或文件无法验证”，不泄露内部细节。只有簿内操作延长闲置，其他页操作不延长。最小化、托盘、5分钟闲置等锁定立即移除内容，未保存编辑丢弃；复制状态只说“已复制，未被替换时30秒后清除”，不在提示里显示密码。

30秒时若系统剪贴板被占用，显示“剪贴板正被占用，未能自动清除”；可提示稍后复制非敏感内容，不能显示已清除。复制成功与清除成功为两个独立反馈，后者只在系统操作确认后显示。

F-06b：修改主密码→验证旧密码→新密码两次→保存中→完成并锁定→新密码解锁。失败保留旧簿，给重试入口。

F-06c：恢复→选加密备份→输备份密码并验证→“恢复将替换整个密码簿”→先备份现有簿入口→设置新的本机主密码→第二次确认→替换→锁定。错误、损坏或取消均保留旧簿；准备时锁定取消，密文提交开始后显示不可取消进度但锁定仍立即遮盖。

## UI-06 课表

```text
[学期设置] [上一周] 第7周 [下一周] [回到本周] [新增课程]
时间/节次 | 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日
每格：课程名、教师、地点、节次、实际时间、特殊时间/冲突标记
点击课程 → 名称/教师/颜色/有效周/单双周/备注
           时段列表 [加时段] 星期 节次 地点 [特殊时间]
```

F-07：添加时段→可选特殊起止→保存前计算冲突→列出冲突课程、共同周次及实际重叠时间→“返回修改/仍然保存”→确认后两门均显示标记。节次不同也可能冲突，相接时间不冲突。非周一起点提示“请选择周一作为第1周开始”；跨午夜提示“请拆为两天的时段”。修改节次时间时预览影响课程及新增冲突，确认后整体保存。

结束时间可选24:00，表示当天结束，开始不能选24:00；例如周一23:00—次日01:00须由用户拆为周一23:00—24:00、周二00:00—01:00，两段的教学周分别确认。

## UI-07 外观设置

```text
[浅色/深色/自定义] 主题色/强调色/文字颜色
[内置/纯色/渐变/本地图片] [选择图片] 遮罩
字体100%—150%  减少动态效果：跟随系统
[即时预览] [恢复默认] [保存状态]
缺图：原背景未随普通备份导入 [导入图片包] [重新选择]
```

F-08：普通配置恢复→颜色字体恢复，图缺失用默认背景→导入独立图片包→找到匹配背景→“应用/暂不应用”；取消应用不丢新导入图片，当前背景不切换；以后可在此应用。损坏/超大图片解释限制并保留当前可用背景。

## UI-08 数据管理

```text
普通数据（明文；不含密码簿和背景图片）：[导出] [合并导入] [覆盖导入]
密码簿（独立加密）：[进入备份/恢复]
背景图片包：[导出] [导入]
自动快照：日期/内容摘要/大小，最多7份 [恢复]
保存/恢复状态：[正在处理…]
危险操作：[清除全部本地数据]
```

F-05：选普通文件→校验→选择模式。合并进入差异列表（字段｜现有｜导入），每条四选项“保留现有/使用导入内容/同时保留为两条/跳过本条”→关联影响预览→全部处理完才可提交→先备份→统一提交→统计。副本规则默认停止、单期副本转独立任务的说明必须出现在确认页。覆盖则显示全量替换预览（新增/替换/将移除的明细），明确“文件中没有的现有普通记录将移除”，二次确认后才统一提交。取消预览不改任何业务；失败：“导入未完成，已恢复原数据”，若回滚本身失败则“需要恢复，已暂停编辑”，展示可用恢复入口，不能谎称已恢复。

F-09：清除入口→完整范围列表＋三个导出入口→输入“清除全部数据”→第二确认说明不可恢复→停止编辑并清除→首次引导。外部备份不删除；中断后继续清除，界面说明未完成并可重试。后台保护副本没有单独用户恢复入口，不与7份快照混淆。

## UI-09 设置

```text
启动：开机启动 [默认关]
运行：关窗进托盘说明；托盘 暂停提醒/恢复提醒/彻底退出
提醒：隐藏标题内容；暂停状态；时区说明（跟随系统本地钟点）
快捷键：快速记录组合键 [验证]；应用内快捷键说明
密码簿：闲置锁定时长、自动隐藏时长
关于：1.0.0、离线说明、数据目录、许可证、帮助
```

首次关窗“程序将继续在托盘运行并提醒，彻底退出后不再提醒”；托盘暂停/恢复操作反馈明确，重启到期集中展示；不开机自启不等于卸载提醒规则。设置失败保留旧值并说明下一步，自动保存状态与普通页面一致。

## UI-STATE 通用状态约定

空状态提供该页一个主要新建入口；加载中不闪现“空”；保存中不能显示成功勾；保存失败保留草稿；导入失败区分已回滚与待恢复；密码簿锁定不保留敏感缩略文字；缺图保留颜色字体；删除和清除的取消可返回原焦点。读屏可获取状态文本，短暂提示同时保留可查的错误区域。所有图示仅设计审阅，需V-UI/系统实测。
