## 二、基础设置、外观与首次引导

### 设置持久化

使用 T04 的普通存储服务和串行队列，新增白名单设置查询/修改接口。修改携带 baseRevision 和 clientMutationId，主进程逐键校验，不开放任意 payload、路径或通知账本。多个设置编辑器需协调 revision；修改一个字段必须保留其他字段，不能将旧的整份设置写回覆盖最新值。

本阶段实际提供：

- 通知隐藏内容：沿用已实现的 privacyNotification。
- 基础主题：跟随系统、浅色、深色；默认跟随系统。
- 字体：100%、125%、150%，默认100%。
- 减少动态效果：跟随系统、始终减少。沿用 reduceMotion=false 表示跟随系统，true 表示始终减少，文档明确该语义；使用系统媒体查询动态更新有效效果，不把系统状态写回用户偏好。
- 应用内快捷键说明及未来快速记录快捷键的格式校验/候选设置；本阶段不宣称已完成全局注册冲突检查。
- 打开首次引导、版本、未发布状态、数据位置与许可证说明。

自定义配色、背景图片及图片包留 T11，密码簿参数留 T09。主题和字号通过受控 CSS 变量或固定样式类应用，不允许用户提供任意 CSS、脚本或远程样式。

现有 schemaVersion=1 的字段足以承载上述业务设置，不为基础主题和动态效果新增无必要的格式版本。主进程仅返回相关设置 DTO，不返回普通正文或密码数据。

### 首次引导与提示标记

首次进入显示简短可键盘操作的引导，说明普通数据默认未加密、独立密码簿与主密码不可找回、关闭窗口进入托盘、彻底退出停止提醒、普通/密码簿/图片三类迁移，以及备份与清除位置。对尚未开发的功能说明当前状态。

将“已看引导”和“已看首次关窗提示”作为本机 UI 元数据，放在应用管理的 runtime/ui-state.json，独立固定版本、主进程白名单读写、原子保存，不纳入普通业务快照或业务备份。损坏时重置提示标记即可，不重置业务数据。未来全部清除应包含该文件。重看引导入口常驻设置页。

## 三、托盘、关闭窗口与彻底退出

将当前“关窗即退出”改成产品规定的“关窗进托盘”。主进程明确区分隐藏、最小化、托盘恢复与彻底退出，替换现有 window-all-closed 退出处理，避免 before-quit 与 close 互相递归。

- 托盘使用本地打包图标，菜单提供打开主窗口、暂停/恢复提醒、彻底退出。
- 首次关窗解释托盘行为，允许返回应用或继续；确认前不能先隐藏。
- 关窗隐藏前 flush，失败时保留可见窗口与草稿，不静默隐藏失败提示。
- 托盘双击或打开、第二次启动均恢复同一个窗口；最小化时先 restore 再 show/focus。
- 彻底退出前 flush，沿用重试、返回应用、确认放弃的既有语义；退出完成后销毁托盘并注销本进程的系统资源。
- 若托盘创建失败，保留窗口并说明原因，不能隐藏成用户无法找回的进程。

暂停/恢复只修改 reminderPause 并显示明确状态。本阶段调度尚未实现，界面不得声称已经产生或投递任务通知。为 T08 预留受控状态接口，为 T09 预留最小化/隐藏/锁屏的锁定事件契约，不把尚未实现的处理计为通过。

开机自启默认关闭。本阶段实现用户主动开关与安全调用入口：仅打包环境允许注册，使用固定产品启动目标并校验结果，不接受网页传入路径或启动参数；失败保留旧状态并反馈。开发/预览环境禁用该开关并说明需在打包版验证，不能把 Electron.exe 或测试入口注册为自启。普通数据恢复不能主动开启系统自启，实际注册仍需用户操作。安装版和便携版的真实自启行为留分发验证，不能以模拟单元测试声称通过。

## 四、键盘、缩放和保存体验

按 Step 2 UI-BASE 实现：Tab/Shift+Tab、Enter/Space、Esc，弹窗焦点约束、关闭后返回触发位置；无鼠标也能访问导航、设置、恢复和退出。

- Ctrl+S 用于实际可保存设置；Ctrl+N 只在已实现的新建场景启用，否则不截获。Ctrl+K 可打开明确标注尚未接入业务的搜索入口，不能返回虚假结果。
- 快捷键不能覆盖输入框编辑与中文输入法组合输入。
- 长错误信息可读、可查、可聚焦；异步保存状态有合理的读屏提示，不逐键播报。
- 状态用文字/图标同时表达，焦点不能只靠背景色。
- 主窗口最小尺寸以960×640逻辑像素为初值，小工作区适配可用区域并允许滚动；不能用缩小文字逃避布局问题。
- 测试字体100/125/150%、系统缩放100/125/150/200%，超出当前环境可测项明确登记。

Step 4 已记录100k实体保存可能持续约12秒，不能把等待10秒简单判为磁盘失败。本阶段区分“仍在处理”“明确失败”和“界面失联”：可确认的长保存显示等待，退出请求期间防止重复提交且不丢草稿。不要通过更早显示“已保存”、取消事务校验或阻塞整个渲染界面来缩短等待。

### 必需验证

1. 九页键盘可达，默认首页正确，无业务假成功，恢复模式仍能进入恢复操作。
2. 设置重启持久；并发设置修改、旧响应、重复请求、冲突与保存失败不覆盖数据。
3. 首次引导和首次关窗提示、重看入口、标记损坏及重置范围正确。
4. 关窗进托盘、托盘打开、最小化后恢复、二次启动唤醒，始终只有一个实例；托盘失败不隐藏。
5. 退出保存成功、失败后重试、返回保留草稿、确认放弃，以及长保存超过10秒的行为。
6. 暂停状态与菜单、页面一致，自启默认关闭且开发环境不能注册实际系统项。
7. 主题、字体、系统减少动态效果实时生效；小工作区、长中文提示和中文输入法无严重遮挡。
8. 新接口的合法调用、非法参数、未授权窗口和路径注入检查通过，原有 CSP、沙箱与资源权限不退化。
9. 新增托盘后，联网状态观察启动、隐藏、恢复和托盘待机30分钟；记录进程树及覆盖限制。执行断网资源模拟，物理断网未做则标未执行。

自动化测试与实际Windows操作分别记录。使用虚构数据和独立测试目录，不改真实自启配置或个人数据。历史人工UI证据涉及的源码若变化，应重做受影响操作并更新绑定，不能伪造旧记录继续适用。更新证据门槛时按实际检查项目核实完整性，不只改通过数量。
