## 问题与修复

1. `scripts/electron-test.mjs` 原先在报告缺失/复制失败时只打印错误，退出码仍可能为0；未检查报告中的失败项。新增 `evidence-gate.mjs` 校验报告结构、数量、重复名称和结果状态；缺失、损坏或失败均返回失败。离线模拟仅允许明确的两项网络观察标为未执行，不冒充已通过。
2. 原先超时设置的失败退出码可能被子进程退出回调覆盖。新增独立超时标志，最终退出码必须同时满足正常退出、未超时、证据有效。
3. 首次复测实际出现 `PEER_LOCK_FAILED`：剪贴板测试辅助进程仅尝试一次获取系统锁。现在最多20次、间隔50ms重试，仍失败则明确退出；不修改产品模块，不放宽“占用时必须返回busy”的断言。
4. 新增4项回归测试并接入 `npm test`，覆盖证据缺失/截断、失败/重复结果、限定的离线未执行项、超时及异常退出。
